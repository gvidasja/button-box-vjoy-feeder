# button-box-vjoy-feeder

vJoy feeder app for a custom button-box

## Installation

prerequisite - install Wails
```
go install github.com/wailsapp/wails/v3@latest
```

production build and run:
```
.\build.ps1 # and run it
```

dev build and run
```
# optionally uncomment OpenDevTools() line
wails3 dev
```
